# Roadmap

## 0.1 available locally

SQLite and CSV capture, Python iterator integration, authenticated comparison and a documented version 1 format.

## Next milestones

- Validate the detached workflow with three independent SQLite operators and three teams that own CSV export or migration checks. Measure time to first successful compare and collect synthetic reproductions of cases they cannot express.
- Add a mutation corpus with application export edge cases and additional cross-language vectors. Invite an independent verifier implementation.
- Evaluate a PostgreSQL snapshot adapter or a Parquet adapter after real adopter workflows show demand. Define type and transaction semantics before adding each format.
- Evaluate local bucket diagnosis if mismatch follow-up is a frequent blocker. Keep row-level output an explicit local operation.
- Expand binary channels only if the Python dependency blocks adoption.

Dates and additional features depend on maintainer time and pilot results. [Launch and adoption](docs/adoption.md)
