# Security

Version 0.1.x is the supported line while releases are in alpha. Use a patched Python distribution and SQLite runtime.

Report a vulnerability through the repository's Security tab using private vulnerability reporting if enabled. If the repository host has no private channel, use the publisher's documented private contact and request one before sending sensitive material. Include affected versions, a minimal synthetic reproduction, and impact. Keep production keys, rows and receipts out of public issues.

Anyone with the comparison key can generate valid receipts. Manage keys through a separate secure channel and treat receipts as sensitive metadata. See the security boundaries and operational assumptions in the [architecture](docs/architecture.md) and [protocol](docs/protocol.md).
